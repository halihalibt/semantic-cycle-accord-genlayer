# SCA-3 V1 Work Master Plan

Authoritative repository: `halihalibt/semantic-cycle-accord-genlayer`.
Sole target: Stable Studionet, 61999, `https://studio.genlayer.com/api`.
SCA-3 is a new protocol; no prior account project is a source or design baseline.

| Phase | Scope | Status |
| --- | --- | --- |
| 1 | Stable compatibility, deterministic contract/storage/state machine, INV-01–16, local tests, public unmerged checkpoint | Implemented and locally verified; draft checkpoint for approval |
| 2 | Legitimate custom Leader/Validator full three-edge semantic assessment, decision equivalence and assessment persistence | NOT AUTHORIZED / NOT STARTED |
| Later product phase | Separate Project using the same primitive; Repository B and frontend | NOT AUTHORIZED / NOT STARTED |
| Later evidence phase | Authorized manual deployment, real finalized consensus and product integration | NOT AUTHORIZED / NOT STARTED |
| Submission phase | Separate Intelligent Contracts and Projects readiness/review | NOT AUTHORIZED / NOT STARTED |

Future phases require separate explicit approval. Phase 1 authorization does
not authorize merge, deployment, transaction submission, faucet use, signing,
private-key access, paid AI services, another network, frontend, Repository B,
Portal submission, or AI implementation.

Read `PROJECT_CHECKPOINT.md`, all specifications and the Phase 1 report before
continuation. Preserve frozen semantics: exactly three wallets/ring edges,
all required edges FIT for semantic acceptance, independent Validator complete
classification, immutable full terms, three owner confirmations, ACTIVE as
agreement rather than delivery, and bounded deterministic operations.

Phase 2 must replace no deterministic safeguard and expose no verdict setter.
It must rerun deterministic preflight after consensus, because versions,
expiration or reservations may invalidate the candidate. No administrator may
substitute for consensus. No convenience equivalence mechanism may stand in
for independently re-executed decision-field validation.
